# Příloha C – Glosář a definice metrik (v2)

| Pojem | Definice v tomto dokumentu |
|---|---|
| **FOP** | Fyzická osoba podnikající – v analýze synonymum pro OSVČ / živnostníka (vč. svobodných povolání a zemědělců). |
| **OSVČ hlavní / vedlejší** | Dle ČSSZ: hlavní = povinná účast na důchodovém pojištění (platí min. zálohy); vedlejší = souběh se zaměstnáním, studiem, důchodem – účast podmíněná příjmem. |
| **Registrovaný vs. aktivní FOP** | Registrovaný = platné živnostenské oprávnění (RŽP) / zápis v RES (ČSÚ). Aktivní = evidovaný u ČSSZ s vykonávanou (nepřerušenou) činností. |
| **PO** | Právnická osoba podnikající: s.r.o., a.s., družstvo, spolek s podnikatelskou činností. |
| **Small business (SB)** | Pracovní definice v2: FOP + PO s ročním obratem **do 50 mil. Kč**. |
| **Mikropodnik / malý podnik (EU)** | Doporučení 2003/361/ES: mikro < 10 zam. a obrat nebo bilance ≤ 2 mil. EUR; malý < 50 zam. a ≤ 10 mil. EUR. |
| **MSP** | Malé a střední podniky (< 250 zam., ≤ 50 mil. EUR obrat). |
| **Živnostníci (ČNB, S.14)** | Podsektor domácností v měnové statistice ČNB; úvěry a vklady FOP vykazované odděleně od nefinančních podniků (S.11). |
| **NII / NIM** | Čistý úrokový výnos / čistá úroková marže (NII ÷ průměrná úročená aktiva). |
| **CoR** | Cost of risk – náklady na riziko (tvorba opravných položek ÷ průměrné úvěry), v % nebo bps. |
| **NPL** | Non-performing loans – úvěry se selháním (Stage 3 / „v selhání“ dle ČNB) ÷ úvěry celkem. |
| **RWA** | Rizikově vážená aktiva. |
| **ROE / ROTE** | Návratnost (hmotného) vlastního kapitálu. |
| **C/I** | Cost-to-income – provozní náklady ÷ provozní výnosy. |
| **CAC** | Customer acquisition cost – náklad na získání klienta. |
| **ARPU** | Average revenue per user – průměrný roční výnos na klienta. |
| **NPS** | Net Promoter Score – % promotérů (9–10) − % kritiků (0–6). |
| **RM** | Relationship manager – bankéř přiřazený klientovi (business bankéř / firemní poradce). |
| **RBF** | Revenue-based financing – financování splácené podílem z tržeb (např. Flowpay, Lemonero). |
| **Embedded finance** | Bankovní produkt nabízený uvnitř nebankovní platformy (účetní SW, e-shop systém, platební brána). |
| **FIDA** | Financial Data Access Regulation – návrh EU nařízení o přístupu k finančním datům („Open Finance“), rozšiřuje open banking za platební účty. |
| **PSD3 / PSR** | Třetí směrnice o platebních službách / nařízení o platebních službách – nový rámec EU nahrazující PSD2. |
| **IPR** | Instant Payments Regulation – nařízení EU o okamžitých platbách v EUR (termíny pro non-euro státy 2027). |
| **ViDA** | VAT in the Digital Age – balíček EU k digitálnímu DPH reportingu a e-fakturaci. |
| **AMLR / AMLD6 / AMLA** | Nařízení a směrnice EU proti praní peněz; AMLA = nový evropský AML orgán. |
| **Bank iD** | Česká bankovní identita (společný podnik bank) – ověření identity a kvalifikovaný podpis (QSIGN). |
| **Paušální daň** | Režim od 1. 1. 2021 pro OSVČ neplátce DPH (limit příjmů dle platné úpravy, 3 pásma od 2023); jedna měsíční platba daně a pojistného. |
| **2T repo sazba** | Hlavní měnověpolitická sazba ČNB; kotva pro sazby kontokorentů a úvěrů. |
| **ARAD / RES / RŽP / SBS** | Databáze časových řad ČNB / Registr ekonomických subjektů ČSÚ / Registr živnostenského podnikání MPO / Strukturální statistika podniků ČSÚ. |
| **Značky** | `[FACT]` ověřeno ve zdroji s URL a datem · `[EST]` odhad autora (výpočet uveden) · `[EXTRAP]` extrapolace · `[DATA GAP]` nenalezeno, uvedeno kde hledat · `[STALE]` zdroj k nabídce starší než 06/2026 · `[CLAIM]` marketingový výrok bez nezávislého ověření. |
| **Cut-off 06/2026** | Popis současné nabídky bank (produkty, ceny, funkce) smí vycházet jen ze zdrojů datovaných červen 2026 nebo později. |
